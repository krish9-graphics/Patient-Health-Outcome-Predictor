
# Patient Health Outcome Predictor

## About the Project
A machine learning-based academic project that predicts patient health outcomes
and provides dashboard-based analysis using Streamlit.

## Main Features
- Patient health outcome prediction
- Patient history and prediction record storage
- Disease analysis for diabetes, hypertension, heart disease,
  kidney disease and respiratory disease
- Treatment and risk analysis dashboards

## Technology Stack
- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- SQLite
- Plotly and Matplotlib

## Model
The deployed model is Logistic Regression.
The target classes are Improved, Stable and Deteriorated.

## Run Locally
1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required packages from the project's requirements file.
4. Run the Streamlit application using its actual file path.

## Disclaimer
This project is for academic demonstration and decision-support
research only. It is not a medical diagnosis tool.
